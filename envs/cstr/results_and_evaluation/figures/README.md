# CSTR Figures

The trajectory folders are grouped by the final evaluation outcome of each
training run. For the baseline, this grouping uses `success_rate`; for RML and
manual-RM variants, it uses `rml_success_rate`.

The trajectory plots are generated by replaying `best_model.zip` for each seed,
not `model_final.zip`. A seed can therefore appear under `failed_seeds` if its
final checkpoint failed the reported evaluation metric, while the trajectory
inside that folder succeeds because the best checkpoint from the same run
succeeded earlier. Conversely, a seed can appear under `successful_seeds` if its
final checkpoint succeeded, even when the best-checkpoint replay is less
representative.

This convention keeps aggregate reported results tied to the final trained
policy, while trajectory figures show the clearest qualitative behavior found
during training. The folder names should therefore be read as final-evaluation
outcomes, not as direct labels of the replayed trajectory outcome.
